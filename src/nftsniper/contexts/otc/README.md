# Контекст: OTC (правка к ТЗ — см. docs/TZ.md §11)

Прямая оплата листинга пересылкой TON из self-custody кошелька
(TON Keeper) продавцу — без маркетплейса и без эскроу.

Состояние сделки:
`awaiting_payment → paid → completed` (+ `expired`, `cancelled`).

- `paid` — бот видит on-chain пересылку на адрес продавца на точную
  сумму с комментом-идентификатором сделки (до TTL).
- `completed` — покупатель подтвердил получение NFT.
- Безопасность: срок оплаты (TTL), точная сумма + memo, явные
  предупреждения о P2P без эскроу, возраст кошелька продавца в деталке.

Реальное наблюдение пересылок появится вместе с ChainPort;
пока — dev-адаптер и in-memory хранилище (заменится на Postgres).
